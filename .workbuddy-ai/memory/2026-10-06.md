## 构建报错根因（用户表示先不管）
- IDEA 全局 HTTP 代理 `C:/Users/Beigu/AppData/Roaming/JetBrains/IntelliJIdea2025.3/options/proxy.settings.xml`
  里 `USE_HTTP_PROXY=true / 127.0.0.1:7890`，而 7890（Clash 类）没在跑 → Gradle 所有下载 `Connection refused`。
- 三个解法：① 启动 7890 代理；② IDEA → Settings → Appearance & Behavior → System Settings → HTTP Proxy 改成 No proxy / Auto-detect 再 sync；③ 开 Gradle Offline mode（LWJGL 3.3.2 等依赖本地缓存齐全）。
- 注意：IDEA 运行中改 `proxy.settings.xml` 可能被退出时覆盖，建议走 UI。
