### 环境坑（本轮遇到）
- `:common:jar` 报 `Could not add file ... .class to ZIP ...-dev.jar` → 是 build 产物被锁/半写（两个 java 进程 = Gradle daemon 占用）。
  处理：`./gradlew --stop` 停掉所有 daemon（`tasklist | grep -c java` 归零）后再删/重建。
- 本环境的删除被 `safe-delete` 包装（走 genie-trash），文件被占用时会报 `trash operation: Some operations were aborted`，
  这不是权限问题，是占用问题。
- `PowerShell` 工具在本会话里 stdout 不回显（命令 exit 0 但无输出）→ 改用 Bash/Python 取信息。
